# SKYLiGHT Auto-Ban plugin

Unofficial Nicotine+ plugin, version 1.2.0.

Install this folder into your Nicotine+ plugins directory. See the repository root [README](../README.md) for full installation steps, configuration, troubleshooting, privacy notes, and limitations.

Default behavior:
- Checks search-result users whose result paths contain `DASH`.
- Matches `SKYLiGHT` and `skylight.beer` case-insensitively in a profile description.
- Adds matching usernames to the persistent ban list and, by default, the ignore list.
- Does not IP-ban users or make external HTTP requests.
