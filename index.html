Small plugin. Practical automation.

The plugin watches search-result events and requests profile information only when a returned path matches the configured release marker.

01 / DETECT

Signature-based detection

Match profile phrases such as SKYLiGHT and skylight.beer case-insensitively instead of relying on a single username.

02 / ACT

Automatic ban and ignore

Add matching usernames to Nicotine+'s persistent ban list and, by default, its ignore list.

03 / CONTROL

Request limits

Configure the result marker, the number of concurrent requests, and timeouts.

How it works

  1. A search result contains a path matching the configured marker, DASH by default.
  2. The plugin queues that username and requests profile information through Nicotine+'s built-in User Info service.
  3. The returned description is checked against the configured phrases.
  4. On a match, the username is banned and optionally ignored.

The plugin acts after a matching result appears and a profile response is received. It does not identify accounts pre-emptively across the whole network.

Install in a few steps

  1. Download v1.2.0.
  2. Close Nicotine+ and remove any older skylight_autoban folder.
  3. Extract the plugin folder into Nicotine+'s plugins directory.
  4. Make sure __init__.py sits directly inside skylight_autoban, not inside a duplicate nested folder.
  5. Restart Nicotine+, open Settings → General → Plugins, enable the plugin, and apply.

Default settings

Review these values in the plugin settings. Clearing the path marker can generate many more profile requests.

SettingDefaultPurpose
profile_keywordsSKYLiGHT, skylight.beerCase-insensitive phrases in profile descriptions.
release_group_markerDASHOnly checks result users whose paths contain this marker. Empty means all result users.
also_ignoretrueAlso add matches to the ignore list.
max_concurrent_profiles3Concurrent profile requests.
profile_timeout_seconds8Seconds before a request times out and the queue advances.

Limitations and privacy

Does it ban IP addresses?

No. It bans usernames and optionally ignores them. It does not IP-ban, reducing the risk of affecting unrelated users on shared addresses.

Does it catch every new account?

No. An account must appear in a matching search result and return profile information. Changed profile wording or release tags can evade the defaults.

Does it send data elsewhere?

No external HTTP requests or telemetry are used by this plugin.

Is it official?

No. This is an unofficial community project, not affiliated with Nicotine+ or Soulseek.
